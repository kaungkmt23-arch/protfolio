# NXY LI — ポートフォリオ制作事例

**役割:** フルスタック開発（個人制作）
**技術:** FastAPI・SQLite・JS/Reactランタイム
**種別:** ポートフォリオ作品

「実際に形にできる」ことを示すための、フルスタックECサイト実装。モックアップではなく、本当に動くストアです。

---

## 01 — 概要

NXY LI は、キーボード・モニター・デスク・チェアなどワークスペース関連のプレミアム商品を扱うオンラインストアです。実在のビジネスではなく、フリーランス案件で提供できるECサイト体験の水準を示すためのデモ制作物。商品閲覧・絞り込み・カート・決済・アカウント作成まで、静的なデザインファイルではなく実際のデータベースとAPIで動作します。

目標は、クライアントが実際にクリックして最後まで試せるものを作ることでした——商品をカートに入れ、決済まで進み、アカウントを作成する。そのすべてを体験してもらい、同じ丁寧さを自分のサイトにも期待してもらえること。

## 02 — 技術構成

**フロントエンド**
HTML/CSS/JSを直接記述し、ビルド工程を持ちません。`{{ }}` / `sc-for` / `sc-if` という軽量テンプレート構文を、実行時にReactへコンパイルする独自の仕組みを採用。Reactもローカルに同梱しており、外部依存はゼロです。

**バックエンド**
FastAPI + SQLAlchemy + SQLite。商品・カート・注文・メルマガ登録・JWT認証それぞれのルーターを実装しています。

## 03 — 実装した機能

- カテゴリー・接続方式・価格で絞り込める商品一覧（グリッド／リスト表示切替）
- リロードやタブ間でも保持される永続カート
- 実際のバックエンドに接続した、決済 → 注文作成 → 完了画面までの一連のフロー
- 会員登録・ログイン・ログアウト・セッション保持に対応したアカウント機能
- 幅390pxでの実機検証まで行ったレスポンシブ対応（見た目だけの調整ではありません）

## 04 — デザインの意図

配色とタイポグラフィは「装飾」ではなく「意図」が伝わるように選びました。温かみのあるストーン系の背景に、ほぼ黒に近いテキスト。インタラクションの要所にのみ使う、控えめなデニムブルーのアクセント。見出しには文学的な重みのあるセリフ体、本文にはグロテスク体のサンセリフ、価格やラベルなどシステム的な要素にはモノスペース体を使用しています。機能的でありながら仕上げに気を配った、商品そのものの世界観と呼応する組み合わせです。

| トークン | Hex |
|---|---|
| ストーン（背景） | `#ECEAE4` |
| インク（文字） | `#16150F` |
| デニム（アクセント） | `#3F5D8C` |
| フェイント（サブ） | `#8A877E` |
| カード | `#F4F2EC` |

## 05 — 実際に見つけて直した不具合

どんな制作物にも、作った後に見えてくる負債があります。ここが制作事例として一番意味のある部分です——機能一覧ではなく、実際に何が壊れていて、どう直したか。

**描画バグ** — テンプレートの未解決プレースホルダー（`{{ p.img }}`）が、JSの読み込み完了前にそのまま画像URLとしてリクエストされていました。全ページで404エラーとSVGアイコンの表示崩れが発生。テンプレート属性を `data-*` に退避し、コンパイラ側でマッピングし直すことで、ブラウザがハイドレーション前にそれらへ触れないよう修正しました。

**モバイル致命的** — リンク切れのナビ項目が、モバイル表示でカートボタンを画面外（右へ89px）に押し出していました。スマートフォンではカートに一切アクセスできない状態。レスポンシブのブレークポイントを全ページで再設計し、目視ではなく幅390pxでの実測検証まで行いました。

**バックエンド** — 会員登録が実は機能していませんでした。`passlib` と `bcrypt` のバージョン不整合により、登録リクエストのたびにサーバーがエラーで落ちていました。サーバーログから原因を特定し、互換バージョンに固定して解決。

**アセット漏れ** — 注文完了画面で商品サムネイルが表示されていませんでした。画像URLを生成するスクリプトの読み込みが、そのページだけ抜けていたのが原因。修正自体は一行でしたが、すべての注文完了画面に影響する不具合でした。
